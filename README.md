Hamilo Client

A custom Minecraft Java Edition 1.21 client project built with Fabric.

Current Features

- Custom client GUI
- Right Shift GUI toggle
- Designed for Java 21
- Buildable as a Fabric mod JAR

Requirements

- Minecraft Java Edition 1.21
- Fabric Loader
- Java 21

Build

Use Gradle to build the project:

./gradlew build

The compiled JAR will be located in "build/libs/".
